Amazon Clone – Full-Stack E-Commerce Application

Amazon Clone is a full-stack e-commerce web application built to simulate key features of Amazon, including product browsing, cart management, checkout, and order tracking. 
It provides a modern shopping experience with authentication, payments, and a responsive UI.

🚀 Features:
👤 User Authentication – Register, login, and manage accounts
🛍 Product Listing – Dynamic product catalog with details
🛒 Shopping Cart – Add, update, and remove items
💳 Checkout & Payment Integration – Supports UPI, Card, Wallet, COD (Razorpay/Stripe integration)
📦 Order Management – Place orders & view order history
📊 Admin Panel – Manage products, users, and orders
📱 Responsive UI – Works on desktop & mobile devices

Tech Stack:
Frontend: HTML, CSS, JS, Bootstrap
Backend: Python(Django)
Database: Psql-PG admin
Payment Gateway: Razorpay
